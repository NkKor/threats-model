# threats-model

Автоматизация формирования модели угроз безопасности информации.

Веб-сервис по методике ФСТЭК (2021): пошаговый опрос пользователя → предпросмотр
модели угроз на веб-странице → выгрузка итогового отчёта в XLSX/DOCX.

* код сервиса и документация — [`threat-modeler/`](threat-modeler/README.md)
* источники данных рабочего каталога — [`справочники/`](справочники),
  `бдму.xlsx`, `сводная таблица.docx`, `УБИ-объект.docx`, `Итоговые таблицы.docx`
* отчёты о ходе работ — [`plans/`](plans)

## Быстрый старт

PowerShell (Windows, без Docker):

```powershell
cd threat-modeler
.\start.ps1            # venv + зависимости + БД + сервер на 0.0.0.0:8080
```

Сервис: <http://localhost:8080>. Коллеги из локальной сети обращаются по
адресу `http://<IP-машины>:8080` (в скрипте выводятся доступные адреса;
при необходимости разрешите входящие подключения к порту 8080 в брандмауэре).

Локальный запуск, структура проекта, правила корреляции и открытые вопросы —
в [README сервиса](threat-modeler/README.md).
